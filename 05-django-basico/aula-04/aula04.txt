Nesta aula, aprendemos a configurar a navegação entre a página principal e a página de imagem usando o recurso de URL name no Django.

Inicialmente, a navegação não funcionava corretamente porque o href nas imagens da página principal apontava para "imagem.html", o que gerava um erro. Para corrigir isso, fizemos o seguinte:

    Adicionamos name='imagem' ao path da página de imagem no arquivo urls.py.
    Substituímos imagem.html por {% url 'imagem' %} no href das imagens em index.html.

Depois, para permitir a navegação de volta para a página principal a partir da página de imagem, fizemos o processo inverso:

    Adicionamos name='index' ao path da página principal no arquivo urls.py.
    Substituímos index.html por {% url 'index' %} no href do botão "Home" em imagem.html.

Essas alterações garantiram que a navegação entre as páginas aconteça de forma dinâmica e correta, utilizando os nomes das URLs registradas no Django.
