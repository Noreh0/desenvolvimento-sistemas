começamos a expandir nosso projeto de restaurantes para incluir o cardápio. Para isso, os instrutores nos guiaram na criação de uma estrutura organizada usando o paradigma de orientação a objetos.

Os pontos principais foram:

    Criação da pasta cardapio: Para organizar melhor o código, foi criada uma nova pasta cardapio dentro de modelos, onde as classes relacionadas ao cardápio serão armazenadas.
    Criação da classe ItemCardapio: Esta é a classe base para todos os itens do cardápio. Ela possui um construtor (__init__) que define os atributos _nome e _preco, que são comuns a qualquer item.
    Criação das classes Prato e Bebida: Foram criadas duas novas classes, Prato e Bebida, que também terão seus próprios construtores. A ideia é que elas herdem as características básicas de ItemCardapio, mas também tenham atributos específicos (como descricao para Prato e tamanho para Bebida).

Os instrutores destacaram que, no próximo vídeo, será abordado como associar Prato e Bebida à classe ItemCardapio por meio do conceito de herança, fazendo com que ItemCardapio seja a "classe mãe".

conceito de herança em Python, que permite que uma classe herde características de outra classe.

Os instrutores mostraram como fazer isso na prática, utilizando a classe ItemCardapio como base. As classes Prato e Bebida foram criadas para herdar os atributos nome e preco de ItemCardapio.

Para indicar a herança, você viu que é preciso importar a classe base e, na declaração da subclasse, colocar o nome da classe base entre parênteses, como em class Prato(ItemCardapio):.

Dentro do construtor das subclasses (__init__), foi utilizado super().__init__(nome, preco) para chamar o construtor da classe pai e inicializar os atributos herdados. Além disso, você viu que é possível adicionar atributos específicos a cada subclasse, como descricao para Prato e tamanho para Bebida, sem se prender apenas às informações da classe base.

A principal vantagem destacada é a manutenção de um padrão e uma linha de raciocínio para todas as classes que compartilham características em comum.

incluir itens no cardápio de um restaurante.

Primeiro, foi adicionado um atributo _cardapio como uma lista vazia na classe Restaurante, no arquivo restaurante.py.

Em seguida, foram criados dois métodos: adicionar_bebida_no_cardapio() e adicionar_prato_no_cardapio(). Ambos os métodos recebem um objeto (bebida ou prato, respectivamente) e o adicionam à lista _cardapio usando o método .append().

Por fim, no arquivo app.py, você viu como usar esses novos métodos para adicionar uma bebida (bebida_suco) e um prato (prato_paozinho) ao restaurante_praca.

O próximo passo será criar um método para listar esses itens do cardápio.

Nesta aula, você aprendeu sobre a importância de refatorar o código para evitar repetições e torná-lo mais eficiente e fácil de gerenciar.

Os instrutores mostraram como unificar os métodos de adicionar bebidas e pratos no cardápio em um único método chamado adicionar_no_cardapio(). Para isso, foi utilizada a função isinstance() para verificar se o item a ser adicionado é uma instância da classe ItemCardapio ou de uma de suas classes filhas.

Essa abordagem permite adicionar qualquer tipo de item ao cardápio (bebidas, pratos, sobremesas, etc.) sem a necessidade de criar um método específico para cada um, o que simplifica bastante o código e facilita a manutenção.

O próximo passo será exibir o cardápio de forma organizada.

aprendemos a criar um método para exibir o cardápio de um restaurante. Começamos definindo o método exibir_cardapio() dentro da classe Restaurante e o marcamos com @property para que ele seja uma propriedade de leitura.

Para organizar a exibição, incluímos o nome do restaurante e usamos um for loop com enumerate() para listar os itens do cardápio, começando a contagem do 1. Inicialmente, exibimos apenas o nome e o preço dos itens.

Em seguida, para lidar com as diferenças entre pratos (que têm descrição) e bebidas (que têm tamanho), utilizamos a função hasattr() para verificar a existência desses atributos em cada item. Assim, conseguimos exibir a descrição para pratos e o tamanho para bebidas, tornando a apresentação do cardápio mais completa e organizada.

Por fim, testamos a funcionalidade no app.py para garantir que o cardápio estava sendo exibido corretamente, com todos os detalhes específicos de cada tipo de item.
