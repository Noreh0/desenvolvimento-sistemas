Estrutura Básica de um Documento

Todo documento HTML começa com uma estrutura padrão indispensável. No seu editor de código (como o VS Code), você pode gerar esse esqueleto automaticamente digitando os atalhos rápidos abaixo e pressionando Enter:

  • html:5
  • !
template-padrao.html
<!DOCTYPE html>
<html lang="pt-BR">
<head>
    <meta charset="UTF-8">
    <title>Minha Primeira Página</title>
</head>
<body>
    <!-- O conteúdo visível vai aqui -->
</body>
</html>

Guia de Tags HTML

Estrutura

html

A raiz de qualquer documento HTML. Ela avisa o navegador de que tudo o que está dentro dela é um código HTML e engloba absolutamente todo o conteúdo da página.

Atributos Comuns:
lang Define o idioma principal do documento (ex: "pt-BR" para português do Brasil). Fundamental para SEO e acessibilidade.
index.html
<html lang="pt-BR">
    <!-- Todo o código do site vai aqui -->
</html>
Resultado no navegador:

Visualmente, a tag <html> é invisível, ela serve apenas como contêiner raiz.

Estrutura

head

É a "cabeça" do código da página. Ela guarda configurações do sistema, metadados e arquivos externos vinculados (como arquivos CSS e JS) que ajudam a página a rodar corretamente, mas não são desenhados diretamente na tela.

head.html
<head>
    <meta charset="UTF-8">
    <title>Título na Aba</title>
</head>
Resultado no navegador:

Nenhum elemento contido no <head> (com exceção do título da aba) é desenhado na tela do site.

Estrutura

meta

Define metadados da página. Ela fornece informações como o conjunto de caracteres usado (acentuação), configurações de responsividade mobile e descrições do site para buscadores. É uma tag autônoma (se fecha sozinha).

Atributos Comuns:
charset Define a codificação de caracteres. O padrão "UTF-8" garante que acentos e emojis funcionem.
name / content Cria pares de chave/valor para configurações como responsividade (viewport) ou descrição para SEO.
metadados.html
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width">
Resultado no navegador:

Sem a tag <meta charset="UTF-8">, palavras com acentuação como "Ação" podem aparecer quebradas: "AÃ§Ã£o".

Estrutura

title

Define o título que aparece na aba do navegador quando o usuário acessa seu site. Também é o título principal exibido nos resultados de busca do Google.

titulo.html
<title>Página de Aprendizado HTML</title>
Resultado no navegador:
Página de Aprendizado HTML
Estrutura

body

O "corpo" do site. Absolutamente tudo o que você deseja apresentar visualmente para o usuário final (títulos, textos, imagens, vídeos, botões) deve ser inserido entre a abertura e fechamento desta tag.

corpo.html
<body>
    <h1>Visível na Tela!</h1>
</body>
Resultado no navegador:

Visível na Tela!

Divisão

div

Um contêiner genérico em bloco. Serve para criar caixas invisíveis para agrupar elementos que pertencem à mesma seção ou grupo, tornando muito fácil estilizá-los e movê-los em conjunto usando CSS.

caixa.html
<div style="background: #fff; padding: 10px;">
    <p>Texto dentro do caixote</p>
</div>
Resultado no navegador:

Texto dentro do caixote (estilizado pela div)

Semântica

header

Define o cabeçalho visível do seu site ou de uma seção específica. É comumente utilizado para envolver o logotipo, o título da página ou a lista de links de navegação principal.

cabecalho.html
<header>
    <h2>Meu Logotipo</h2>
</header>
Resultado no navegador:
Meu Logotipo
Semântica

main

Engloba o conteúdo central, principal e exclusivo de uma página. Deve haver apenas um elemento <main> por página, e ele ajuda bastante os buscadores a entenderem o foco de cada URL.

conteudo.html
<main>
    <p>Conteúdo exclusivo da página.</p>
</main>
Resultado no navegador:

A tag <main> age como um contêiner estrutural semântico importante para acessibilidade.

Semântica

section

Representa uma seção autônoma de conteúdo temático dentro de uma página (como "Sobre Nós", "Serviços Prestados" ou "Depoimentos"). Ajuda a segmentar o documento logicamente.

secao.html
<section>
    <h3>Sobre Nós</h3>
    <p>Nossa missão é ensinar código.</p>
</section>
Resultado no navegador:
Sobre Nós

Nossa missão é ensinar código.

Semântica

footer

Define o rodapé de um site ou de uma seção. Costuma carregar informações de autoria, dados de copyright (direitos autorais), links para termos de uso ou políticas de privacidade e redes sociais.

rodape.html
<footer>
    <p>© 2026 Senac - Todos os direitos reservados.</p>
</footer>
Resultado no navegador:
© 2026 Senac - Todos os direitos reservados.
Texto

h1 a h6

Estruturam títulos e subtítulos nas páginas. O <h1> é o mais importante e deve ser único por página, enquanto os subtítulos de menor importância semântica seguem a ordem até <h6>.

titulos.html
<h1>Título H1</h1>
<h2>Subtítulo H2</h2>
Resultado no navegador:

Título H1

Subtítulo H2

Texto

p

Representa um parágrafo comum de texto. É um elemento de bloco e insere automaticamente um espaçamento antes e depois do texto para garantir uma leitura agradável e separada.

paragrafos.html
<p>Meu primeiro parágrafo.</p>
<p>Meu segundo parágrafo.</p>
Resultado no navegador:

Meu primeiro parágrafo.

Meu segundo parágrafo.

Navegação & Links

a

Cria um link (âncora) para direcionar o usuário para outro site ou arquivo.

Atributos Comuns:
href A URL de destino (ex: "https://google.com").
target Use "_blank" para abrir em uma aba nova.
link.html
<a href="https://google.com" target="_blank">
    Ir para o Google
</a>
Resultado no navegador:
Ir para o Google
Texto

strong

Exibe um texto em negrito, indicando que as palavras têm forte importância semântica no conteúdo. Além de mudar a aparência visual para o leitor, é interpretada por leitores de tela para pessoas com deficiência visual.

destaque.html
<p>
    Isso é <strong>muito importante</strong>!
</p>
Resultado no navegador:

Isso é muito importante!

Texto

span

Um contêiner de linha (in-line). Não altera a quebra de linha nem a formatação padrão. É extremamente útil para selecionar um trecho específico de texto em um parágrafo e estilizar apenas aquele pedaço com CSS.

linha.html
<p>
    Aprender HTML é <span style="color: purple">incrível</span>.
</p>
Resultado no navegador:

Aprender HTML é incrível.

Mídia

img

Exibe imagens na página. É uma tag vazia que não precisa de fechamento. Ela aponta para o endereço da imagem e a desenha diretamente na tela.

Atributos Comuns:
src O caminho ou link direto para o arquivo de imagem (ex: "foto.jpg").
alt Texto descritivo alternativo que aparece se a imagem falhar, usado por leitores de tela.
imagem.html
<img src="https://picsum.photos/120/80" alt="Foto exemplo">
Resultado no navegador:
Listas

ul

Cria uma lista não-ordenada. É a clássica lista de tópicos onde os itens são marcados com pequenos círculos ("bullets") ou marcadores e a ordem lógica dos itens não interfere na semântica.

lista-desordenada.html
<ul>
    <li>Arroz</li>
    <li>Feijão</li>
</ul>
Resultado no navegador:
  • Arroz
  • Feijão
Listas

ol

Cria uma lista ordenada. Os itens recebem numeração sequencial automática (1, 2, 3...) ou letras (a, b, c...) para indicar um passo a passo ou ranking.

Atributos Comuns:
type Altera o estilo do marcador (ex: "1" para números, "A" para letras maiúsculas, "I" para algarismos romanos).
lista-ordenada.html
<ol type="1">
    <li>Abrir o editor</li>
    <li>Escrever o código</li>
</ol>
Resultado no navegador:
  1. Abrir o editor
  2. Escrever o código
Listas

li

Define um item de lista. Esta tag não pode ficar solta e deve ser colocada obrigatoriamente dentro de uma tag mãe <ul> ou <ol>.

Atributos Comuns:
value Altera o valor numérico padrão do item atual (somente dentro de listas ordenadas).
item.html
<ol>
    <li value="10">Item número 10</li>
</ol>
Resultado no navegador:
  1. Item número 10
Formulário

form

Envolve e gerencia toda a área do formulário. É o contêiner principal que agrupa os inputs e gerencia o processo de envio dos dados para um servidor.

Atributos Comuns:
action Define o endereço do servidor ou arquivo para onde os dados serão enviados.
method O método HTTP de envio ("GET" exibe dados na URL, "POST" os envia de forma oculta).
formulario.html
<form action="/salvar" method="POST">
    <!-- Campos do formulário ficam aqui -->
</form>
Resultado no navegador:

Assim como o <html>, a tag <form> é invisível na tela, servindo para processamento.

Formulário

input

O campo onde o usuário insere dados. É uma das tags mais versáteis do HTML5, pois seu tipo de input determina o comportamento visual (caixa de texto, senha, e-mail, etc.). Se fecha sozinha.

Atributos Comuns:
type Muda o tipo de entrada (ex: "text", "email", "password", "submit").
placeholder Dica opaca de preenchimento que some quando o usuário começa a digitar.
campo-input.html
<input type="text" placeholder="Digite seu nome">
Resultado no navegador:
Formulário

label

O rótulo textual associado a um campo de input. Melhora consideravelmente a acessibilidade e permite que o usuário clique no texto do rótulo para focar ou selecionar o input ligado a ele.

Atributos Comuns:
for Deve ser exatamente idêntico ao id do input correspondente para ligar ambos os elementos.
rotulo.html
<label for="nome">Nome:</label>
<input id="nome" type="text">
Resultado no navegador:
Formulário

button

Cria um botão clicável na página. Pode ser usado tanto para submeter dados no formulário quanto para disparar ações interativas adicionais no JavaScript.

Atributos Comuns:
type Define a função do botão ("submit" envia os dados, "button" apenas cria um botão genérico para interagir).
botao.html
<button type="submit">Enviar Dados</button>
Resultado no navegador:
Superpoderes

< Atributos Globais />

Os atributos globais são parâmetros especiais que você pode adicionar a praticamente **qualquer** tag HTML na sua página. Eles agem como "superpoderes" que ajudam a identificar, estilizar ou configurar elementos específicos de forma uniforme.

Classificação

class

Classifica a tag para que o CSS ou JavaScript a encontre facilmente. Várias tags diferentes podem possuir a **mesma class** para compartilharem o mesmo estilo visual ou comportamento.

exemplo-class.html
<p class="aviso-importante">Texto 1</p>
<p class="aviso-importante">Texto 2</p>
Identificador Único

id

É o CPF da tag. Um identificador único que **não pode se repetir** na mesma página do site. Muito usado para criar âncoras internas no link e manipulações cirúrgicas no JavaScript.

exemplo-id.html
<main id="conteudo-principal">
    <!-- Apenas um elemento main com este ID -->
</main>
Estilo Inline

style

Permite injetar regras de estilo de CSS diretamente dentro da própria tag. Embora seja extremamente prático para correções ou testes rápidos, é recomendado separar o estilo em arquivos CSS apartados para maior organização.

exemplo-style.html
<p style="color: blue; font-size: 18px;">Texto estilizado na hora!</p>
Resultado no navegador:

Texto estilizado na hora!
